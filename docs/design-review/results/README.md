膨脹與評審誤差觀察：

- 基準與對手的截圖每輪都相同，分數卻在漂移：基準 mean 6.21 → 5.96 → 6.38，r3 的 overall 比 r2 高 0.5；對手 mean 6.29 → 6.71 → 6.58。新版與基準的差距要扣掉這個幅度來看。
- r1 評審說新版議題卡「報導角度／政黨觀點」全為 0 仍照樣顯示；查 r1 新版頁面，只有兩張有非零值的卡片顯示這兩列，屬評審誤讀，未據以修改。
- r3 新版的 `channel_mobile.png` 是一張空白圖：主機負載尖峰（load1 曾到 187）中瀏覽器被終止後重拍失敗，不是產品問題（同狀態的深色版正常）。這讓 r3 新版的「響應式」分數偏低。之後擷取工具把沒有文字的頁面視為失敗並重拍。
- r4 的新版截圖在 sky-server 上因負載長期高於 10 卡在閘門，未完成；評審未進行。

各輪修改見 git 記錄（`First core-page pass`、`Round 1 fixes`、`Round 2 fixes`、`Round 3 fixes`）。
