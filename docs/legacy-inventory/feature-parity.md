## Remaining Operator Or External Follow-up

The items below do not represent scaffolded Laravel features:

1. Production polling or allowlist changes require explicit operator approval, exact dry-run evidence, a current backup, and a rollback plan.

5. Legacy API consumers can migrate to clean URLs after replacement consumers are known; compatibility routes remain covered in the meantime.
