# Scheduler Parity

Ground truth is `/Users/skyhong/Documents/youtube-board-legacy/urtube/cron` plus the standalone `maint/*.php` scripts. This file tracks the legacy scheduling and write semantics against Laravel commands. Public `https://youtube.board.tw` behavior is secondary only.

Safety defaults:

- `INGESTION_SCHEDULER_ENABLED=false` by default; runtime env must explicitly enable scheduler registration.
- `php artisan ingestion:run` is dry-run unless `--execute` is supplied.
- Registry-driven scheduler execution uses capped `scheduled_execute_command` values for scheduled-write jobs.
- Scheduler-enabled polling is fail-closed. Scheduler/local-or-Production polling gates must be explicitly true and an exact allowlist must include the job before its capped scheduled command can run.
- Commands that can write must print their write targets and must keep dry-run as the default.
- Secrets are checked through env/config and are never printed.
- Activation and promotion rules are documented in [scheduler-activation.md](scheduler-activation.md). Manual local `--execute` smokes are not scheduled write polling; scheduled write-capable jobs require capped commands, rate limits, quota handling, and local/production safety gates.

## Activation Design

See [scheduler-activation.md](scheduler-activation.md) for the detailed activation model. Current implementation supports dry-run previews, scheduled ingestion jobs, explicit local `--execute` smokes, and capped scheduler execution for jobs with `scheduled_execute_command`. Production remains governed by the existing Dokploy scheduler, polling gates, quota budget, job locks, and exact allowlist; this work does not modify those runtime values or add manual-only builders to Production scheduling.
