# Release 83e0bc9（2026-10-17）：管理後台第二層分頁、頻道管理表、帳號活動

## 內容

正式版 5210420（含 1050e8a 紀錄）加上 `e521dc4`、`83e0bc9`。沒有 migration、沒有 env 變更，也沒有 Laravel 變更。
main 上的 a005492（關鍵字一鍵排除）**不在**這個 image 裡；main 的 2b190cd 是兩者的合併。

- `/manage` 各頁上方加上和 `/my` 一樣的第二層分頁：頻道｜事件與頻道審核｜關鍵字覆核｜帳號。帳號選單的管理連結改成只有「管理後台」（`/manage`）。
- `/manage` 改為頻道管理表：所有收錄過的頻道（含已封存），收錄狀態（統計逾期／尚未抓到影片／近 30 天無新片／正常／已封存）、分類、訂閱、影片、7 天新片、最新影片、統計更新、加入時間。
  可搜尋名稱、YouTube ID 或編號，用分類和狀態篩選，篩選上的數字會套用其他條件；點欄名排序，每次顯示 200 筆。
- `/manage/users` 改為帳號活動表：互動（追蹤、收藏、有效 API 金鑰、RSS）、貢獻（事件編輯、頻道提名、頻道審核、角色調整）、最近活動、最近登入、登入裝置，可排序。
- 新 API（只限管理員 session，`private, no-store`）：
  - `GET /auth/admin/channels`：報表帳號讀 `urt_channel`、`urt_count`、`urt_video`、`urt_tag`，正式資料 3,889 筆約 0.55 秒、1.2 MB。
  - `GET /auth/admin/user-activity`：state 帳號依序讀 `ts_reader_*`、`ts_auth_sessions`、`ts_auth_role_audit`、`ts_editorial_audit`，約 20 ms。
  - 關鍵字覆核、頻道提名、抓取退避的表不在網站帳號的權限內，所以沒有算進來，方法區塊有寫。
- 說明文字都放在「本頁的資料來源與計算方式」區塊。
