# 介面易用性審查（2026-10-21）

依 Nielsen 十大易用性原則審查使用者提供的 12 張截圖與對應元件。代號：

| 代號 | 原則 |
| --- | --- |
| H1 | 系統狀態可見 |
| H2 | 系統與真實世界一致（使用讀者的語言，不用內部術語） |
| H3 | 使用者控制與自由 |
| H4 | 一致性與標準 |
| H5 | 預防錯誤 |
| H6 | 辨識優於回想 |
| H7 | 彈性與使用效率 |
| H8 | 美感與極簡設計 |
| H9 | 協助辨識、診斷與復原錯誤 |
| H10 | 說明與文件 |

嚴重度：**高** 影響找資料或誤導判讀；**中** 增加閱讀成本；**低** 細節。

## 需要另外決定（資料或 API 語意，未修改）

1. 停用詞：`platform/api/src/reports/stopwords.ts` 的固定清單區分大小寫（`LINE` 擋得到、`Line` 擋不到），也沒有 `訂閱`、`IG`、`FB`、`Threads`、`LIVE` 與純數字（`2026`、`20`）。可改固定清單、在 `tags.no_tag` 加詞，或在 `cloud.ts` 改成不分大小寫並排除純數字。
2. API 給的篩選欄名是內部用語：「期間（起訖優先）」「結束日往前偏移」「開始邊界（不含）」。
3. `/channels/:id/trends` 有兩組完全相同的欄位（「七日移動估計（次）」與「七日移動估計」、「相鄰日實測觀看差」與「估計每日觀看」）。
4. `/mayor` 的「分類日桶」用語（`lib/bucket-coverage.ts`）與占比顯示三位小數。
5. `/groups` 的更新時間是 2023/01/24（API meta）。
6. 直播子分頁名稱（期間、逐時…）過短（2.5），保留舊站對應。
