# Shared visual and interaction family

The shell is adapted directly from the maintained tag.observe.tw source (read-only reference checkout `tag.analysis.tw`), with its MIT notice retained in `upstream/tag-observe-LICENSE`. Header, grouped desktop/mobile navigation, search, theme toggle, scroll reset, navigation progress, footer band and wide-table primitives follow the same implementation and dimensions. The container is `max-w-6xl` with 16px side padding; fonts use the identical PingFang/Noto Sans TC/Noto Sans CJK TC/Microsoft JhengHei/system stack.

The product is 有影儀表板. The selected default is the mother-family stacked wordmark with a miniature legacy urtube ring/play symbol between the lines; `/about/brand` retains the legacy redraw and original alternatives. YouTube red `#FF0000` is the primary brand token; darker red text and lighter dark-mode text retain contrast. Navigation and footer links describe actual YouTube reports and maintained shared vocabulary. Google reader login, following, saves, personal RSS and role-controlled administration are implemented using this project’s own sessions/data. News collection totals, reading-telemetry reports and install prompts are not presented as implemented YouTube features.

The header search targets video titles/descriptions, shares the100-character API limit and retains current q on results. Theme resolution uses the saved explicit preference or system color scheme before first paint and follows later system changes when no override exists. Mobile menus close on Escape/outside press, restore focus on Escape, and close at the desktop breakpoint. Separate mutually hidden desktop/mobile navigation instances preserve DOM focus order at both breakpoints. Manually opened mobile search preserves text and restores its opener on Escape; automatically visible search retains field focus. Reduced motion disables the progress animation and smooth back-to-top scrolling.

`TableScroller` isolates horizontal overflow, offers a keyboard-focusable region, shows continuation fading, measures the sticky/following header and keeps identifying columns visible. On small screens the lead cell contracts from9.5rem to5.5rem after horizontal scrolling. Missing archive metrics and source coverage remain explicitly identified.
